# Catálogo de venta de equipos usados

Página estática (HTML + JSON + fotos). Para publicarla con GitHub Pages:

1. Crea un repositorio nuevo en GitHub y sube todo el contenido de esta carpeta (index.html, items.json, img/ y .nojekyll).
2. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → Branch: main / (root) → Save.
3. En 1–2 minutos la página queda en https://<usuario-u-organizacion>.github.io/<repositorio>/

Para actualizar datos de un equipo, edita items.json. Las fotos están en img/ con el formato <número><A|B|C>.jpg.
